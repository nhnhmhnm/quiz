# Quiz

Python으로 구현한 CLI 기반 퀴즈 게임 프로젝트입니다.
파일 I/O, OOP, 예외 처리, Git 워크플로우 학습을 목표로 합니다.
이 퀴즈는 곧 개봉하는 **오디세이**에 맞춰, 원전이 되는 오디세우스 신화를 쉽고 가볍게 익힐 수 있도록 오디세이아 기반 퀴즈를 제작했습니다.

## 프로젝트 구조

```
quiz/
├── main.py                 # 진입점 (경량화)
├── config.py               # 설정 상수
├── state.json              # 데이터 저장소
├── README.md
└── game/                   # 핵심 패키지
    ├── __init__.py
    ├── game.py             # 퀴즈 풀기 로직
    ├── quiz_manager.py     # 퀴즈 추가/삭제/목록
    ├── record.py           # 랭킹 / 히스토리
    ├── storage.py          # JSON 로드/저장
    └── menu.py             # 메뉴 UI
```

## 메뉴 구성

```
========== QUIZ ==========
1. 퀴즈 풀기
2. 퀴즈 관리
3. 기록
4. 종료
==========================
```

### 1. 퀴즈 풀기
- 이름 입력 후 시작 (빈 값이면 자동으로 `UNKNOWN` 저장)
- 등록된 퀴즈 중 **랜덤 10개**로 출제
- 종료 후 점수와 함께 랭킹/히스토리에 기록

### 2. 퀴즈 관리
```
[등록된 퀴즈 목록]
1. Python의 창시자는? / Guido van Rossum
2. ...

A. 퀴즈 추가
D. 퀴즈 삭제
0. 돌아가기
```

### 3. 기록
- **전체 랭킹:** 상위 3명 표시
- **개인 기록:** 이름 입력 → 해당 사용자 기록 전체 표시
- **정렬 기준:** 점수 내림차순 → 최근 플레이 시간 내림차순

```
1. 전체 랭킹 (TOP 3)
2. 개인 기록 조회
0. 돌아가기
```
